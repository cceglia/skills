# Goravel Inertia

`github.com/goravel/inertia` integrates Inertia.js with Goravel's HTTP lifecycle, sessions, validation and routing. Use `inertia-core` for protocol semantics.

## Versions

- **Adapter v1.18.0:** read [versions/v1.18.0.md](versions/v1.18.0.md) before configuring or using this release. It targets Inertia.js v3.

Identify the installed adapter version in `go.mod` before selecting a reference. If it is not listed, consult that version's tagged documentation and source; do not assume v1.18.0 behavior applies.
