# Inertia core

Inertia.js defines the HTTP protocol and client behavior for server-driven page visits, independently of the server adapter and UI framework.

## Versions

- **Inertia.js v3:** read [versions/v3.md](versions/v3.md) before applying protocol or client guidance.

Identify the project's installed Inertia client and adapter versions before selecting a reference. If the relevant version is not listed, consult that version's official documentation and installed adapter; do not assume v3 behavior applies.
